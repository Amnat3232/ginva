# GINVA Guardian Messaging Framework

> *"Ginva ไม่ใช่ arena ที่คนล่าคน แต่เป็น community ที่คนพิทักษ์กันและกัน"*

---

## 🎯 Core Message

**Ginva คือป้อมปราการ — ไม่ใช่สนามรบ**

- ไม่มีใครต้องเสียเพื่อให้คนอื่นได้
- ทุกคนมีหน้าที่พิทักษ์กัน
- ยิ่งมีคนเข้ามา = ยิ่งปลอดภัย = ทุกคนได้ประโยชน์

- "Community" / "ชุมชน"
- "Safe haven" / "ท่าน้ำปลอดภัย"
- "Together we stand" / "ยืนหยัดด้วยกัน"
- "ปราการ" / "ป้อม" / "รัง"

- "Hunter" / "นักล่า"

## 🎨 Visual Language

### สีที่ใช้
- 🟢 เขียวเข้ม (ความมั่นคง)
- 🔵 น้ำเงิน (ความไว้วางใจ)
- ⚪ ขาว (ความบริสุทธิ์)
- 🟡 ทอง (รางวัล/คุณค่า)

### สิ่งที่ควรมีใน visual
- 🏰 ป้อมปราการ/ประตูเมือง
- 🛡️ โล่/เกราะ
- 🌅 พระอาทิตย์ขึ้น (ความหวัง)
- 🤝 มือจับมือ
- 🌳 ต้นไม้ (การเติบโตที่ยั่งยืน)
