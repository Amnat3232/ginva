## 🎯 Key UX Principles

1. **ความปลอดภัยต้องเห็นได้ชัด** - โล่และสีเขียวต้องเด่น
2. **ความเร่งด่วนต้องไม่กดดัน** - นับถอยหลังแบบสงบ ไม่กระพริบเร็ว
3. **ทางเลือกต้องชัดเจน** - 3 ตัวเลือกที่ต่างกันชัดเจน
4. **ข้อมูลต้องครบถ้วน** - แต่ไม่รก ใช้ accordion ซ่อนรายละเอียด
5. **การดำเนินการต้องง่าย** - ปุ่มใหญ่ ชัดเจน ไม่ต้องคิดมาก
