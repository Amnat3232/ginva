## 🎯 Key UX Principles

1. **Safety must be visible** - Shields and green colors must be prominent
2. **Urgency without pressure** - Calm countdown, no fast flashing
3. **Clear choices** - 3 distinct options clearly different
4. **Complete information** - But not cluttered, use accordion for details
5. **Easy actions** - Big buttons, clear, no overthinking needed
