## 🎯 GINVA คืออะไร?

> **GINVA = "กระจายรายได้ ส่งมอบความสุข ให้ความปลอดภัย สร้างความไว้วางใจ"**

### เรื่องเล่าจากโลก DeFi

**ก่อน GINVA:** คุณมีคริปโตที่เชื่อมั่นในอนาคต แต่ต้องการเงินสดใช้จ่ายตอนนี้ ตัวเลือกมีสองทาง:

- ขายคริปโต → ขาดทุนโอกาสเมื่อราคาขึ้น
- กู้จากแพลตฟอร์ม DeFi → กลัวโดนยึดทรัพย์กลางดึกโดยไม่มีโอกาสแก้ไข

> 💭 _"ตอนนั้นผมมี ETH แต่ต้องจ่ายค่าเทอมลูกด่วน ตลาดกำลังขาลง ถ้าขายตอนนี้คือขาดทุน ถ้ากู้แล้วราคาลงอีก กลัวโดนยึดทันที"_  
> — เสียงจากผู้ใช้ DeFi ทั่วไป

**หลัง GINVA:** Alex ใช้ GINVA ฝาก ETH ไว้ รับ USDC มาจ่ายค่าเทอม 3 เดือนต่อมา ETH ขึ้น 40% เขาใช้กำไรคืนเงินกู้ แล้วได้ ETH คืนครบ ไม่เสียโอกาส ไม่เสียความหลับ

### เราทำสิ่งนี้ได้อย่างไร?

GINVA คือ **แพลตฟอร์มกู้เงินที่ใช้สินทรัพย์ดิจิทัลเป็นหลักประกัน** ที่ถูกสร้างขึ้นบนหลักการ **"ผู้กู้ควรได้รับโอกาสในการรับมือ ไม่ใช่ถูกบังคับชำระบัญชีทันที"**

**อะไรที่ทำให้เราแตกต่าง?** แตกต่างจากแพลตฟอร์มอื่นที่ยึดทรัพย์สินทันทีเมื่อราคาตก **เราให้เวลาคุณ 72 ชั่วโมงเพื่อปกป้องหลักประกันของคุณ**

### 🌳 GINVA: ระบบนิเวศที่เกื้อกูลกัน

> **"กระจายรายได้ ส่งมอบความสุข ให้ความปลอดภัย สร้างความไว้วางใจ"**

GINVA คือต้นไม้ใหญ่ที่เติบโตบน Solana ซึ่งทุกคนเป็นเจ้าของร่วมกัน ไม่มีใครเป็น "ลำดับรอง" แต่ทุกคนเป็น **3 เสาหลัก** ที่ขาดไม่ได้

```
                    🍎 ผลไม้แห่งความสำเร็จ
                           │
              ┌────────────┼────────────┐
              │            │            │
          🌿 ใบไม้      🪵 ลำต้น      🌱 ราก
        ผู้สนับสนุน    ผู้กู้       ผู้ช่วยเหลือ
       (เส้นเลือดใหญ่) (หัวใจ)   (ผู้พิทักษ์)
              │            │            │
              └────────────┴────────────┘
                           │
                    🛡️ ระบบปกป้อง 72 ชม.
                           │
              กระจายรายได้ ส่งมอบความสุข
              ให้ความปลอดภัย สร้างความไว้วางใจ
```

**ทำไมถึงเรียกว่า 3 เสาหลัก?**

- 🌿 **ไม่มีใบไม้** → ต้นไม้ไม่สังเคราะห์แสง (ไม่มีสภาพคล่อง)
- 🪵 **ไม่มีลำต้น** → ต้นไม้ไม่ยืนต้น (ไม่มีผู้กู้)
- 🌱 **ไม่มีราก** → ต้นไม้ไม่รอด (ไม่มีผู้ดูแลความมั่นคง)

**ทุกส่วนมีความสำคัญเท่าเทียมกัน** — นี่คือความหมายของคำขวัญเรา

### 🎬 เรื่องเล่าจากโลกจริง: "คืนที่ผ่านพ้นพายุ"

**สถานการณ์:** คุณฝาก SOL มูลค่า $5,000 ไว้เป็นหลักประกัน เพื่อกู้ USDC มาลงทุนในโปรเจกต์ใหม่

**เหตุการณ์:** วันเสาร์ตอนตี 3 ตลาดคริปโตดิ่ง 30% ใน 2 ชั่วโมง SOL ของคุณเหลือมูลค่า $3,500

#### 🎭 Act 1: การตื่นตัว (The Awakening)

**เวลา ตี 3:15** — คุณได้รับการแจ้งเตือน:

> ⚠️ **"หลักประกันของคุณต้องการการดูแล คุณมีเวลา 72 ชั่วโมง"**

- ❌ **แพลตฟอร์มอื่น:** SOL ถูกขายทิ้งทันทีในราคาต่ำสุด คุณตื่นมาเจอความสูญเสีย
- ✅ **GINVA:** คุณยังหลับสบาย ไม่มีอะไรเกิดขึ้น

#### 🎭 Act 2: การรับมือ (The Response)

**เวลา เช้าวันเสาร์** — คุณตื่นมาเห็นการแจ้งเตือน

ตัวเลือกในมือของคุณ:

- ✅ **เติมหลักประกันเพิ่ม** $1,000 — รักษาสถานะเดิม
- ✅ **คืนเงินกู้บางส่วน** $500 — ลดความเสี่ยง
- ✅ **รอดูสถานการณ์** — ยังมีเวลา 48 ชั่วโมง

คุณเลือกเติมหลักประกันเพิ่มเล็กน้อย แล้วใช้ชีวิตตามปกติ

#### 🎭 Act 3: การฟื้นฟู (The Resolution)

**วันจันทร์** — ตลาดฟื้นตัว SOL กลับมาที่ $4,800

**ผลลัพธ์:**

- 💎 สินทรัพย์ของคุณยังอยู่ครบ
- 💎 ไม่มีการขายขาดทุน
- 💎 คุณมีเวลาคิด วิเคราะห์ และตัดสินใจอย่างมีสติ

> **นี่คือความหมายของ "ให้ความปลอดภัย"** — จากความตื่นตระหนก สู่ความสบายใจ

## 📊 พารามิเตอร์ของโปรโตคอล

| พารามิเตอร์             | ค่า                       | รายละเอียด                              |
| :---------------------- | :------------------------ | :-------------------------------------- |
| **ระบบยึดทรัพย์ A**     | Health Factor (ราคาตลาด)  | ยึดทันทีเมื่อราคาตก (ปกป้องนักลงทุน)    |
| **ระบบยึดทรัพย์ B**     | Maturity + 72 ชม.         | ยึดหลังครบกำหนดไม่ชำระ (ให้โอกาสผู้กู้) |
| **ตัวเลือก LTV**        | 20% / 40% / 60%           | กู้ระดับปลอดภัย / มาตรฐาน / สูงสุด      |
| **ส่วนแบ่งผู้สนับสนุน** | 65.25% ของดอกเบี้ยทั้งหมด | ส่วนแบ่งรายได้ที่มากที่สุด              |
| **ส่วนแบ่งทีมงาน**      | 24.75% ของดอกเบี้ยทั้งหมด | ทีมและการพัฒนา                          |
| **กองทุนสภาพคล่อง**     | 10% ของดอกเบี้ยทั้งหมด    | บัฟเฟอร์ความมั่นคงของระบบ               |
| **กองทุนสำรอง**         | 100% ของส่วนเกิน          | ประกันความเสี่ยงจากหนี้เสีย             |
| **รางวัล Keeper A**     | 0.6% ของหลักประกัน        | สำหรับการตรวจจับและเริ่มยึดทรัพย์       |
| **รางวัล Keeper C**     | 1.0 USDC คงที่            | สำหรับการกระจายรายได้หลังยึดทรัพย์      |
| **ช่วงดอกเบี้ย**        | ขั้นต่ำ 30 วัน            | ระหว่างการจ่ายดอกเบี้ย                  |
| **ความสดของ Oracle**    | สูงสุด 15 วินาที          | ความถูกต้องของข้อมูลราคา                |
